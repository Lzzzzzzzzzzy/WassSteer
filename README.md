# EMNLP' 26 WassSteer Code

This is the code repository for our EMNLP' 26 paper "Fine-Grained Selective Refusal: Steering LLM Safety via Wasserstein-Informed Flow Matching".

The code for this repository is currently under preparation. We are preparing a clean and reproducible implementation including our main method WassSteer, the detailed config for our evaluation and all baselines implementation.
